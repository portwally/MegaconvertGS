MegaconvertGS turns pictures from many computers and file formats into
Apple IIgs Super Hi-Res screens, and saves them in the formats the IIgs and
other computers read. It is a successor to SuperConvert by Jason Harper and
Ian Brumby, and is published with the kind permission of Ian Brumby.

Choose a topic, or use Previous and Next in the bar above to page through
the help. Back returns to the page you came from.

.LOADING
Loading pictures

In the Load formats window, choose the computer the picture comes from
(Computer type), then its format (Specific type), and click Load...
(or double-click the format). The file dialog lists only the files that
format can read; several files may be chosen at once, and a folder's
pictures can all be loaded one after another ("Load all pictures within
selected folders"). Load next then loads the next file waiting.

File > Load any picture... loads a file without choosing its format first:
MegaconvertGS recognises most formats by their file type and contents.

Info on format describes the format chosen in the list.

.SAVING
Saving pictures

Choose a format in the Save formats window and click Save... (or use
File > Save conversion..., Apple-S). Before the file dialog, MegaconvertGS
may ask:
- the size of the saved picture (the original, one screen, a page, two
  screens high or wide, or the selection),
- where a smaller picture goes in a larger area,
- whether to go on when the format cannot hold everything the picture has
  (640 mode, several color tables, mixed modes, dithering),
- the format's own options (Hex data, a Finder icon's criteria; GIF shows
  what to give when uploading the file).
With only a true color or monochrome image, a screen image is made first.

The image window and the three kinds of image

A picture can be held three ways at once: as a screen image (Super Hi-Res
pixels and color tables), as a true color image (red, green and blue for
every pixel) and as a monochrome image (one bit a pixel). The image window
shows one of them: choose which in the pop-up at the left of its info bar.

The other pop-ups choose the tool (selection, or pixel peek showing a
pixel's color), the zoom, and actions: crop to the selection, discard this
kind of image or the others, and use the image's own palette on the screen.

Keys 1-9 and the space bar move around a picture larger than the window.

.REMAP
Remapping true color pictures

A true color picture becomes a screen image through Remap (True color >
Convert to screen, Apple-M). Its dialog chooses the graphic mode (320, 640,
640 dithered, or a different palette for every line), the palette
(calculated for the picture, the default, greys, another picture's, or a
stored one), the rendering (closest color, a pattern, or error diffusion)
and the size. Quick remap previews the result.

.MONO
Monochrome images

Convert to monochrome (in the Screen and True color menus) makes a one bit
a pixel image, enlarged two or four times if wanted, by error diffusion, a
pattern dither, a 50% threshold or a halftone. The Monochrome menu turns it
back into a screen or true color image (its aspect, scaling, mode and how
greys are kept) and makes its negative.

.KEYS
Keys

Apple-L Load & convert, Apple-O Load any picture, Apple-R Re-convert last
file, Apple-N Load next, Apple-S Save conversion, Apple-P Print (enhanced),
Apple-Q Quit. Apple-I and Apple-T: image info; Apple-F, -H and -4: views;
Apple-M: Remap; Apple-A: View approximation; Apple-? or Apple-/: Help.

In the help window: H goes Home, the left and right arrows go to the
previous and next pages, the up and down arrows go Back.

The Apple menu

About MegaconvertGS... shows the program's name and version, and its credits.

Help! opens this window at its first page. Menu item help: choose it, then
choose any menu item to read about it.

Preferences... sets what happens after a picture is loaded or saved: save
it at once, view it full screen or not, open the Remap dialog for true
color pictures (or also after screen images), load the next file waiting
after saving. Save keeps the options for the next time (MCGS.Prefs). "Clear
all SKIP ME preferences" forgets the answers kept by the SKIP ME boxes.

The File menu: saving and more

Save conversion... saves in the format chosen in Save formats (see Saving
pictures). Exchange load/save paths swaps the folders the load and save
dialogs open in.

Print (normal), Print (enhanced) and Print alignment page are not here yet.

Examine file... shows any files, one after another: their data or resource
fork as hex and text, or a histogram of the data fork's byte values (point
at a bar to read its count). Escape or Apple-W closes the window; the arrow
keys scroll.

Quit leaves MegaconvertGS.

The Edit menu

Copy puts the screen image (or its selection) on the Clipboard as a picture
with its color table; Cut does the same and discards the screen image.
Paste and Clear are for desk accessories. Close discards every image and
closes the image window (Apple-W closes the help window when it is in
front).

The Screen menu

Screen image info... describes the screen image: its size, modes and
colors. Convert to true color... makes a true color image from it (a 640
mode picture can be taken exactly, or smoothed: dither patterns become solid
colors). Convert to monochrome... makes a monochrome image.

View full screen, View half size and View X4 magnified show the picture;
a click or a key returns.

The Screen menu, continued

Store palette keeps the picture's colors for Remap's Stored palette choice.

Use as desktop background puts the picture behind the windows of the
programs that use the IIgs desktop; Extras > Revert to normal desktop takes
it away. To keep it, save it as Desktop background image INIT and put the
file in the SYSTEM.SETUP folder of the startup disk.

Oscilloscope Art makes a 320 mode picture to watch on an oscilloscope on
the composite video output: each pair of lines gets its own brightness.

The True color filters

Histogram equalization spreads the picture's brightness over the whole
range. Median and Sigma filters remove noise. Emboss image makes it look
raised. Blur image and Sharpen image soften or sharpen it by a factor.
Solarize image inverts its brighter half. Find edges outlines it. Increase
and Decrease contrast stretch or flatten its colors. Each works on the true
color image; Remap then makes the screen image.

Convert to true color... make the other kinds of image from it: its aspect

its greys to keep. Negative image swaps black and white.
